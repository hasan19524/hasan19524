# Design Language & Decisions

## Theme
- **Premium**: High-quality visuals, clean typography, intentional spacing.
- **Modern**: Up-to-date layout, smooth but subtle animations.
- **AI Engineer Aesthetic**: Structured, modular, system-oriented presentation.
- **Minimal**: No clutter, no random badges, strict focus on content.
- **Futuristic**: Subtle UI elements that imply advanced technology.

## Avoid
- Cluttered badge walls.
- Excessive emojis.
- Template-style layouts.
- Unnecessary or distracting animations.

## Development Standards
- **Folder Naming**: lowercase-kebab-case for directories.
- **File Naming**: UPPERCASE for README, lowercase-kebab-case for assets, lowercase for docs.
- **Markdown Formatting**: Strict line breaks, consistent heading levels, HTML comments for section separation.
- **Image Organization**: \ssets/previews/\ for projects, \ssets/banners/\ for hero sections.
- **Commit Message Convention**: \	ype(scope): message\ (e.g., \eat(hero): add premium banner\).
