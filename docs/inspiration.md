# UI/UX Inspiration & References

## Visual Language Used

- **Accent color:** GitHub blue `#58A6FF` — matches GitHub's native dark UI, feels native rather than bolted-on.
- **Secondary text:** GitHub gray `#8B949E` — subtle hierarchy without hard contrast.
- **Badge style:** `flat-square` — clean, rectangular, no rounded bubble noise.
- **Backgrounds:** transparent (`00000000`) on all stat cards so dark/light GitHub themes adapt automatically.
- **Layout:** centered sections, HTML tables for project cards (GitHub Markdown safe), HTML comments as section dividers.

## Design References

- GitHub's own design system (Primer) — color and spacing cues.
- Premium developer profiles that lead with real, linked projects and proof-of-work rather than badge walls.
- Minimalist aesthetic: every element must earn its place (per docs/design.md).

## Rejected Patterns (why)

- **Badge walls of 30+ tech logos** — reads as keyword stuffing, entry-level signal.
- **Trophy shelves (github-profile-trophies)** — gimmicky, inconsistent rendering, weakens premium feel.
- **"Portfolio Coming Soon" placeholders** — dead links hurt credibility; removed.
- **Unverifiable certification lists** — recruiters may ask for proof; replaced with verifiable achievements.
- **GIF-heavy heroes** — distracting, slow to load, template vibes.
